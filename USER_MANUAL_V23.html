1. Introduction

1.1 What is This Software?

The Serial Data Logger and Plotter is a professional-grade data acquisition system for fatigue testing equipment. It acquires real-time data via serial communication, logs it to disk, displays it on three synchronized plots, and generates professional PDF reports.

Version 2.3 adds:

  • NEW PDF Export - Professional reports with all plots and metadata
  • NEW Modular Architecture - Improved maintainability and code quality
  • NEW Enhanced Metadata - Log filename and complete statistics in reports
  • [OK] All V2.2 features preserved (threshold monitoring, port detection, header logging)

1.2 Key Features

  • Real-time Data Acquisition: Receives data from equipment at 0.1 to 1.0 second intervals
  • Automatic CSV Logging: Data saved with timestamp-based filenames, headers preserved
  • Three Live Plots: Forces, Travel measurements, and Loss of Stiffness monitoring
  • PDF Report Generation: NEW v2.3 Export all plots with comprehensive metadata
  • Threshold Monitoring: Set limits for Upper Force and Loss of Stiffness
  • COM Port Detection: Automatically finds available ports
  • Loss of Stiffness Calculation: Automatic calculation and visualization
  • Watchdog Timer: Alerts if no data received for 5 seconds
  • Mock Data Mode: Test without hardware
  • Unlimited Data Points: No artificial limits on test duration
  • Complete Test Traceability: Device ID and configuration preserved in every log
  • Modular Design: NEW v2.3 Professional architecture for easy maintenance

2. Getting Started

2.1 System Requirements

Python 3.8 or higher

2.2 Installation

Installation Steps:
  1. Install Python 3.8+ if not already installed
  2. Install Dependencies: 
    pip install -r requirements.txt
    Required packages:
    • pyserial >= 3.5

    • pyqtgraph >= 0.13.0

    • numpy >= 1.23.0
    • matplotlib >= 3.5.0 NEW v2.3 (for PDF export)

    python main_application.py

2.3 Quick Start (5 Minutes)

[OK] Quick Start Guide:
  1. Connect Equipment: Plug fatigue tester into COM port
  2. Launch Application: python main_application.py
  3. Detect Port: Click " Detect Ports" button
  4. Select Port: Choose port from dialog, double-click to select
  5. Verify Baudrate: Should be 115200 (default)
  6. Click Connect: Button turns red, plots start updating
  7. Watch Data Flow: Three plots show real-time test data
  8. Data Saved: Automatically logging to logs/ directory
  9. Export PDF: NEW Advanced Options -> Export Plots to PDF

2.4 Testing Without Hardware (Mock Mode)

To test the software without connecting real equipment:

  1. Check "Use Mock Data (Testing)" checkbox
  2. Click "Connect"
  3. System generates realistic test data automatically
  4. All features work identically (plotting, logging, thresholds, PDF export)

4. Connection & Port Detection

4.1 Automatic Port Detection

V2.2+ automatically detects available COM ports on startup:

  1. Auto-Detection: On launch, system scans for available ports
  2. Dropdown Population: Detected ports appear in COM port dropdown
  3. Manual Scan: Click " Detect Ports" to rescan at any time

4.2 Port Selection Dialog

The port selection dialog provides an easy way to choose the correct port:

Using Port Selection Dialog:
  1. Click " Detect Ports" button
  2. Dialog shows all available ports with descriptions
  3. Green [OK] indicates port is available and can be opened
  4. Double-click a port to select and auto-close
  5. Or click "Select" button to confirm
  6. Click "Refresh" to re-scan ports

4.3 Connection Process

  1. Select Port: Choose COM port from dropdown
  2. Set Baudrate: Usually 115200 (default)
  3. Optional: Enable "Use Mock Data" for testing
  4. Click Connect: Button changes to red "Disconnect"
  5. Watch Status: Status log shows connection success

6. Live Plotting

6.1 Three Synchronized Plots

The system displays three real-time plots, synchronized by cycle number:

Plot 1: Forces vs Cycles

  • Blue Line: Lower Force [N]
  • Red Line: Upper Force [N]
  • Orange Dashed Lines: Threshold limits (if enabled)
  • Red Markers: Threshold violations

Plot 2: Travel Measurements vs Cycles

  • Green Line: Travel at Upper Force [mm]
  • Cyan Line: Travel 1 [mm]
  • Magenta Line: Travel 2 [mm]

Plot 3: Loss of Stiffness vs Cycles

  • Orange Line: Loss of Stiffness [%]
  • Formula: (Travel_2 / Travel_at_Upper) x 100
  • Red Dashed Lines: Threshold limits (if enabled)
  • Orange Markers: Threshold violations

6.2 Plot Controls

Control Function Default
Update Interval How often plots refresh (100-5000 ms) 1000 ms (1 second)
Auto Range Automatically adjust axes to show all data Enabled
Clear Plots Remove all displayed data (does not affect CSV log) -
Note: Clearing plots removes visual data but does NOT delete logged CSV data. Your data remains safe in the log files.

7. Threshold Monitoring

7.1 Overview

Threshold monitoring allows you to set acceptable ranges for critical parameters and detect violations in real-time.

7.2 Upper Force Thresholds

Setting Upper Force Thresholds:
  1. Check "Enable Upper Force Thresholds"
  2. Set Upper Limit (maximum acceptable force in N)
  3. Set Lower Limit (minimum acceptable force in N)
  4. System monitors all incoming Upper Force values
  5. Out-of-range values marked in red on plot
  6. Violation count displayed in Statistics Panel

7.3 Loss of Stiffness Thresholds

Setting Loss of Stiffness Thresholds:
  1. Check "Enable Loss of Stiffness Thresholds"
  2. Set Upper Limit (maximum acceptable % in %)
  3. Set Lower Limit (minimum acceptable % in %)
  4. System monitors calculated Loss of Stiffness values
  5. Out-of-range values marked in orange on plot
  6. Violation count displayed in Statistics Panel

7.4 Threshold Visualization

When thresholds are enabled:

  • Threshold Lines: Displayed as dashed lines on plots
  • Violation Markers: Colored dots highlight out-of-range points
  • Violation Counter: Shows total violations in top-left corner of plots
  • Statistics: Real-time violation counts in Statistics Panel
  • PDF Export: NEW Violations included in PDF reports

10. FAQ (Frequently Asked Questions)

10.1 General Questions

Q: What's the difference between V2.2 and V2.3?
A: V2.3 adds PDF export functionality and improves code architecture. All V2.2 features are preserved. The main file is 56% smaller (better maintenance) and you can now generate professional PDF reports of your test data.
Q: Can I use this without hardware?
A: Yes! Enable "Use Mock Data (Testing)" checkbox and click Connect. The system generates realistic test data automatically. Perfect for training or testing the PDF export feature.
Q: Where are my log files?
A: In the logs/ subdirectory next to main_application.py. Files are named fatigue_test_YYYYMMDD_HHMMSS.csv
Q: How do I open the CSV files?
A: Excel, LibreOffice Calc, MATLAB, Python pandas, or any text editor. The format is standard CSV with comment headers (lines starting with #).

10.2 PDF Export Questions NEW v2.3

Q: Do I need special software to view PDF reports?
A: No, any PDF viewer works (Adobe Reader, browser, macOS Preview, etc.). PDFs are standard format.
Q: Can I export PDF during data collection?
A: Yes! You can export at any time. The PDF captures the data collected up to that moment.
Q: Will PDF include my thresholds?
A: Yes! If thresholds are enabled, they appear as dashed lines on plots with violation counts.
Q: How big are the PDF files?
A: Typically 100-500 KB for 1000-10000 data points. Very efficient!
Q: Can I customize the PDF appearance?
A: Not in the GUI currently. The layout is optimized for professional reports. Contact developers for custom requirements.

10.3 Threshold Questions

Q: What happens when a threshold is violated?
A: The violation is:
  • Marked with colored dot on plot
  • Counted in statistics panel
  • Logged in status log
  • Included in PDF report
It's a visual/statistical indicator only - the test continues normally.
Q: Can I change thresholds during a test?
A: Yes! Threshold changes apply immediately. Previous violations remain marked.
Q: Does clearing plots reset violation counts?
A: Yes, clearing plots resets all violation counters.

11. Advanced Features

11.1 Advanced Force Analysis

In the Advanced Options dialog, you can access advanced force analysis:

  • 103% Threshold Analysis: Calculate % of values exceeding (Upper Limit x 1.03)
  • Real-time Updates: Statistics update every 500ms
  • Detailed Breakdown: Shows both count and percentage

11.2 Machine Configuration (CNF Header) NEW v2.3

The Advanced Options dialog displays the Machine Configuration section, which shows all parameters decoded from the CNF header line sent by the fatigue testing device at the start of each connection. This provides full traceability of the test setup.

How it works:
  1. When you connect to the device, it sends a series of header lines followed by a CNF configuration line
  2. The software automatically decodes the CNF binary data into human-readable parameters
  3. Open Advanced Options -> Advanced Settings to view the decoded configuration

Displayed parameters:

Parameter Unit Description
Kraft @2 (upper) N Upper force target for the fatigue test
Kraft @1 (lower) N Lower force target (derived from Kraft @2 / ratio)
Kraftabschaltung N Emergency force cutoff limit
Toleranz @2 % Force tolerance band (+/- percentage around Kraft @2)
Force window N Calculated acceptable force range (Kraft @2 +/- tolerance)
Nachregelweg K1 mm Position-correction budget for Kraft 1
Nachregelweg K2 mm Position-correction budget for Kraft 2
Betaetigungen # Planned total number of test cycles
Messen alle N # Logging interval (log every N cycles)
Device - Firmware version and device ID (if available)
Note: If no device is connected or the CNF header has not been received yet, the Machine Configuration section shows "No configuration available. Connect to the device to receive the CNF header."

12. Technical Information

12.1 Data Protocol

Serial Protocol Format:


DTA;[Cycles];[Pos1];[ForceLower];[Travel1];[Pos2];[ForceUpper];[Travel2];[TravelAtUpper];[Reserved];!

Example:

DTA;31422;182;263;0;793;2238;0;611;0;!
