## What's New in V2.2

### Four Major Features

1. **🔋 COM Port Auto-Detection** (NEW)
   - Automatically detects available serial ports
   - Professional port selection dialog
   - Cross-platform support (Windows, Linux, macOS)

2. **📋 Header Logging & Preservation** (NEW)
   - Device metadata preserved in CSV files as comments
   - Device ID and configuration logged for traceability
   - Standard CSV compatibility maintained

3. **⚙️ Threshold Monitoring** (NEW)
   - User-configurable limits for Upper Force
   - User-configurable limits for Loss of Stiffness
   - Real-time violation detection and visualization
   - Professional red/orange violation markers

4. **🔍 Enhanced Line Filtering** (V2.1 continued)
   - Intelligent filtering of header/config lines
   - No parse errors in status log
   - Statistics tracking for filtering effectiveness
